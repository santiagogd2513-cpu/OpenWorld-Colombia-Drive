### Primer APK
GitHub Actions está configurado para generar el **primer APK** en cada push a `main`.

Configuración Android del juego:
- **Nombre:** OpenWorld Colombia Drive
- **Icono:** personalizado (carretera + atardecer colombiano)
- **Categoría:** Juego
- **Modo inmersivo:** activado (se ocultan las barras de navegación y estado)
- **Package:** `org.colombia.drive.openworld`

Ve a la pestaña **Actions** del repositorio → workflow **Android Build (Godot 4)** → descarga el Artifact cuando termine.

## Controles (teclado / prueba)
- **W** — Acelerar
- **S** — Frenar / Reversa
- **A / D** — Girar
- **Page Up / Page Down** — Avanzar o retroceder el ciclo día-noche
